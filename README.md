# Huistechnieken — Website

Premium website for Huistechnieken BV (Oosterzele).

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Instrument Sans (Google Fonts via next/font)

## Scripts

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Structure

- `src/app/` — routes (App Router)
- `src/components/layout/` — Header, Footer
- `src/lib/services.ts` — service content data
- `src/styles/globals.css` — design tokens + precise-lines

## Design system

Architectural Precision: charcoal / off-white / warm-gray / accent (#2F4A5E).
Border radius 2–4px. Royale whitespace. Editorial service index.

## Content policy

Only verified public data used (address, BTW, year founded).
No fake reviews, project counts, certificates or prices.
Project gallery ready for real cases.
